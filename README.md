# 🛒 DSCommerce

Projeto de desenvolvimento de interface para uma aplicação de e-commerce, desenvolvido utilizando **HTML5 e CSS3**.

O projeto teve como objetivo praticar a construção e organização de interfaces web, criando diferentes páginas e fluxos de uma aplicação de comércio eletrônico e mantendo uma identidade visual consistente entre elas.

## 🚀 Sobre o projeto

O **DSCommerce** apresenta diferentes telas que representam os principais fluxos de uma aplicação de e-commerce, incluindo catálogo de produtos, detalhes de produto, carrinho de compras, login e páginas administrativas.

Neste projeto, o foco foi trabalhar principalmente a estrutura das páginas utilizando **HTML5** e a estilização utilizando **CSS3**, praticando organização de layouts, criação de componentes visuais e reutilização de estilos.

## 📄 Páginas desenvolvidas

- 🏠 Catálogo de produtos
- 🔎 Busca por produtos
- 🛍️ Carrinho de compras

- **HTML5**
- **CSS3**

## 🎨 Interface

O projeto foi desenvolvido buscando manter uma identidade visual consistente entre as diferentes páginas da aplicação.

Foram trabalhados elementos como:

- Cabeçalho e navegação
- Cards de produtos
- Botões
- Campos de busca
- Formulários
- Carrinho de compras
- Catálogo de produtos
- Layout da área administrativa

Durante o desenvolvimento deste projeto, pude praticar:

- Estruturação de páginas utilizando HTML5
- Utilização de HTML semântico
- Organização de arquivos frontend
- Criação e reutilização de classes CSS
- Estilização de componentes
- Estruturação de layouts
- Criação de múltiplas páginas para uma mesma aplicação
- Consistência visual entre diferentes telas
- Organização de código frontend

## ▶️ Como executar

Como o projeto utiliza apenas HTML e CSS, não é necessário instalar dependências ou configurar um ambiente específico.

### 1. Clone o repositório

```bash
git clone https://github.com/gabyferrari/project-dscommerce-html-css-reactjs.git
```

### 2. Acesse a pasta do projeto

```bash
cd project-dscommerce-html-css-reactjs
```

### 3. Abra os arquivos HTML

Basta abrir qualquer arquivo .html diretamente no navegador.

Por exemplo:

```bash
catalago.html
```
